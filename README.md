# JsonPowerDB Micro Project

A micro project built during the Login2Xplore internship selection process.

## Description
This project demonstrates basic database operations using JsonPowerDB (JPDB) REST APIs. It includes a simple web form that performs CRUD operations — Create, Read, Update, and Delete — directly connected to JsonPowerDB without any backend server.

## Features
- Save form data to JsonPowerDB
- Retrieve existing records
- Update records
- Delete records
- Serverless architecture using REST APIs

## Tech Stack
- HTML5
- CSS3
- JavaScript
- JsonPowerDB REST API
- AJAX

## Tools Used
- Talend API Tester
- JsonPowerDB Dashboard
- GitHub
