## Description

This project demonstrates basic database operations using JsonPowerDB (JPDB) REST APIs. It includes a simple web form that performs Create, Read, and Update operations directly connected to JsonPowerDB without any backend server.

## Benefits of Using JsonPowerDB

- Lightweight, schema-free JSON database
- REST API based access for quick integration
- Fast development for prototypes and small apps
- Minimal infrastructure: no dedicated backend server required
- Built-in security and access control options

## Scope of Functionalities

- Save form data to JsonPowerDB
- Retrieve existing records by key
- Update stored records
- Client-side validation before requests

## Examples of Use

- Add a new student record from the form
- Fetch and display a record by ID
- Edit and update a record
- Remove a record when it is no longer needed
